# University Application Tracker

## Description
This project is an interactive dashboard for tracking university applications.  
Users can view deadlines, update application statuses, add new universities, and monitor their overall application progress.

The application loads initial data from a JSON file and updates the interface dynamically using JavaScript.

---

## Features
- Display university applications from `applications.json`
- Add new university applications
- Update application status (Pending, Applied, Accepted, Rejected)
- Filter applications by status
- Search universities by name, program, or country
- View application statistics and progress
- Display upcoming deadlines

---

## Technologies Used
- **HTML5** – page structure
- **CSS3** – layout and styling
- **JavaScript** – interactivity and DOM manipulation
- **Fetch API** – loading data from `applications.json`
- **LocalStorage** – saving user changes in the browser
